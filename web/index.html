Getting it working

Waking a computer over the network needs a few things switched on, once, on the computer you want to wake.

  1. Turn on Wake-on-LAN in the BIOS/UEFI Restart the computer, press the setup key (usually Del, F2 or F10) and look for "Wake on LAN", "Power on by PCI-E" or "Resume by LAN". Set it to Enabled.
  2. Allow the network card to wake the computer On Windows: Device Manager → Network adapters → your adapter → Properties → Power Management → tick "Allow this device to wake the computer".
  3. Use a cable if you can Wake-on-LAN over Wi-Fi only works on some hardware. A wired connection is far more reliable.
  4. Turn off "fast startup" on Windows Control Panel → Power Options → Choose what the power buttons do → untick "Turn on fast startup". Fast startup often blocks waking from a full shutdown.
  5. Keep this program on the same network The wake-up signal is a broadcast and does not normally cross routers. Run this on a machine that stays on — a home server, a mini PC or a router.

Tip: "Find computers" only sees machines that are currently switched on. Turn a computer on, scan for it once, and it stays on your list so you can wake it later.
